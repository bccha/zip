# Zip Manager

Zip Manager는 Electron과 React로 제작된 현대적이고 빠른 파일 압축 및 해제 도구입니다. 직관적인 사용자 인터페이스와 강력한 성능을 제공합니다.

## 주요 기능

- **현대적인 UI**: 다크 모드와 세련된 디자인으로 쾌적한 사용자 경험을 제공합니다.
- **빠른 성능**: 최적화된 알고리즘으로 대용량 파일도 빠르게 처리합니다.
- **다국어 지원**: 한국어, 영어, 중국어, 스페인어를 지원하여 전 세계 사용자가 편리하게 사용할 수 있습니다.
- **간편한 사용**: 드래그 앤 드롭 및 직관적인 버튼으로 압축 및 해제 작업을 쉽게 수행할 수 있습니다.

## 기술 스택

- **Frontend**: React, TypeScript, Vim-like CSS
- **Desktop Runtime**: Electron
- **Bundler**: Vite
